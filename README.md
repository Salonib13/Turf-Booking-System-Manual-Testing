Turf Booking System – Manual Testing Project

• Project Overview

This is an independent manual testing project performed on a Turf Booking System application. The objective was to understand application functionality, execute test cases, identify defects, and prepare QA documentation.

• Project Details

- **Project Name:** Turf Booking System
- **Testing Type:** Manual Testing
- **Testing Approach:** Functional Testing
- **Project Type:** Independent Testing Project

• Modules Tested

- Home Page
- User Registration
- User Login
- Turf Booking
- Slot Availability
- Booking Cancellation
- Admin Dashboard

• Testing Activities

- Prepared manual test cases.
- Executed positive and negative test scenarios.
- Identified application defects.
- Documented defects in bug reports.
- Recorded actual and expected results.

• Test Execution Summary

| Metric | Result |
|---|---:|
| Total Test Cases | 38 |
| Passed | 26 |
| Failed | 12 |
| Pass Percentage | 68.4% |

**Pass Rate Calculation:** (26 / 38) × 100 = 68.42%
